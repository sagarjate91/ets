CHAPTER 1 : INTRODUCTION

1.1 Abstract

This capstone report presents the design and implementation of an Employee Tracking System (ETS), a role-based web application developed using Spring Boot and MySQL. The system centralizes employee data management, attendance recording, leave processing, and user administration. It provides dedicated dashboards for administrators and employees, ensuring secure access and intuitive workflows.

The project follows layered architecture principles with clear separation across controller, service, repository, model, and view layers. Authentication and authorization are implemented with Spring Security and BCrypt password hashing, making the solution suitable for real-world organizational use.

1.2 Introduction

Organizations require a reliable digital system to maintain employee records and day-to-day HR operations. Manual or spreadsheet-based methods create inconsistencies, delay approvals, and limit reporting capabilities. ETS is designed to provide a compact, maintainable, and secure system that streamlines employee and attendance operations while improving visibility for administrators.

The system serves two types of users: administrators who manage all HR operations, and employees who interact with their own attendance and leave data. All interactions are protected by Spring Security, ensuring that no user can access resources beyond their role.

1.3 Problem Statement

Traditional employee record systems often suffer from scattered data, weak access control, and process delays in attendance and leave workflows. The project addresses these issues by developing a centralized portal with role-specific privileges, form validation, and controlled approval pipelines.

  • Lack of centralized digital records for employee information.
  • Manual and error-prone attendance tracking processes.
  • No formal leave request and approval mechanism.
  • Absence of role-based access separation for HR staff and employees.

1.4 Objectives

  • Develop a secure web-based employee information management platform.
  • Implement attendance check-in/check-out with historical records.
  • Provide a leave request and approval workflow.
  • Enable administrators to manage departments, users, and employee profiles.
  • Ensure usability through a responsive UI and clean navigation.

1.5 Scope of the Project

The current scope includes employee CRUD, department management, attendance processing, leave application and approval, and user enable/disable operations. The solution supports two roles: ADMIN and EMPLOYEE. It targets educational and small-to-medium enterprise scenarios and can be extended for enterprise reporting.

2.2 Relevant Technologies Studied

The following technologies were reviewed and selected based on industry adoption, documentation quality, and suitability for the project scale:

  • Spring Boot: Provides auto-configuration, embedded server, and a production-ready foundation for Java web applications.
  • Spring Security: A comprehensive security framework supporting authentication, authorization, and CSRF protection out of the box.
  • Spring Data JPA + Hibernate: Simplifies data access through repository abstraction and ORM mapping, reducing boilerplate SQL.
  • Thymeleaf: A server-side Java template engine with natural HTML syntax, ideal for MVC-based applications.
  • Bootstrap 5: A front-end framework enabling rapid development of responsive, mobile-friendly UI components.
  • MySQL: A widely-used open-source relational database with strong JPA/Hibernate integration.

2.3 Key Design Principles from Literature

  • Role-Based Access Control (RBAC): Separation of admin and employee privileges as a core security principle.
  • Layered Architecture: Clear separation of presentation, business logic, and data access layers for maintainability.
  • DTO Pattern: Using Data Transfer Objects to decouple API boundaries from entity models.
  • Repository Pattern: Abstracting data store operations behind repository interfaces for testability.
